## ⚙️ How to Use skene-cookbook

After installation, you can start using skene-cookbook to add AI skills quickly.

### Running from Your Computer

- Open skene-cookbook.
- You will see a simple menu listing skill categories like marketing or security.
- Select a category to browse skills.
- Click on any skill to learn what it does and how to run it.
- You can run skills with one click or command.

No setup or coding is needed for most skills. The app manages everything in the background.

### Using the Command Line (Optional)

If you feel comfortable with the command line, skene-cookbook lets you install and run skills with simple commands:

1. Open a terminal or command prompt.
2. Type:  
   ```
   skene-cookbook install <skill-name>
   ```
3. Run a skill by typing:  
   ```
   skene-cookbook run <skill-name>
   ```

Replace `<skill-name>` with the skill you want to use.
